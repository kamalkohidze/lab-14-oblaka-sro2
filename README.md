# IoT Temperature Monitor

Веб-сервис для мониторинга температуры с IoT-устройства в реальном времени.

## Описание

Проект состоит из двух частей:
1. **IoT-симулятор** (`iot_simulator.py`) - отправляет данные температуры в HiveMQ Cloud
2. **Веб-сервис** (`app.py`) - получает данные из HiveMQ и отображает их на веб-странице

## Технологии

- Python 3.11+
- Flask (веб-фреймворк)
- Paho-MQTT (работа с MQTT протоколом)
- HiveMQ Cloud (MQTT брокер)

## Установка и запуск локально

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите веб-сервис:
```bash
python app.py
```

3. Откройте браузер: http://127.0.0.1:5000

4. В другом терминале запустите симулятор:
```bash
python iot_simulator.py
```

## Деплой на Render

Сервис автоматически деплоится на Render при пуше в GitHub.
